# 分析/创作交互 v1

本文记录当前已经落地的最小可用闭环，后续分段缩谱、多缩谱和更复杂的配器路由继续沿用这些字段。

## 新建乐谱

新建乐谱的乐器编辑器中，每件乐器可设置：

- `独奏乐器`：设置演奏人数；人数大于 1 时，分配栏按谱表填写，例如 `1,3 / 2,4`。
- `合奏乐器`：生成一个 `SECTION` 演奏者，所有谱表默认归该合奏者。

设置会写入 `StorageOrchestration.players` 与 `staffAssignments`。多位独奏演奏者默认按
连续编号分到谱表；圆号例外，例如四位圆号、两行谱表自动得到 `1,3 / 2,4`。
默认分配的编号会显示在每个系统相应谱表行开头，紧邻乐器名并位于所有括号左侧；
仅有一名演奏者的乐器不显示编号。

## 已创建乐谱中的配器编辑

在“分析/创作”页点击“演奏者/谱表”可以编辑每件已有乐器的独奏/合奏、人数和默认
谱表分配。展开“谱表分配”后，每条谱表为一行，拖动演奏者编号即可换行；这是新建后
调整分配的固定入口。普通乐器按连续编号顺序分行，只有圆号默认交错为 `1,3 / 2,4`。
应用后使用同一个文档撤销栈提交；未参与编辑的乐器和已有谱表保持不变。

## 固定缩谱

第一版只允许一个缩谱。创建缩谱时指定名称、固定谱表行数和每行谱号。缩谱复制主谱的：

- 小节定义、拍号和调号；
- 全局速度与时间轴；
- 页面布局与显示偏好。

因此缩谱与主谱使用同一组 measure/TimeCode 边界。创建时 `links` 始终为空，不询问
映射、演奏者或谱表。

## 直接同步（双向）

分屏中的两侧选区直接提供两个方向，不再打开绑定对话框：

1. **缩谱 → 总谱**：右侧选择唯一活动谱表/声部 → 框选缩谱材料 → 点击上方某位
   演奏者编号，立即写入总谱。
2. **总谱 → 缩谱**：左侧选择活动演奏者 → 框选总谱旋律 → 点击上方某个缩谱
   谱表的声部编号，立即放入该声部。

演奏者和缩谱目标标签均为两行：上行是乐器或缩谱谱表名，下行是编号。每个系统的谱表
行开头显示活动声部/演奏者按钮。缩谱默认全部声部活动；点击按钮后只保留该声部活动，
其他声部变灰；再次点击当前活动按钮恢复全部声部。总谱只允许选择活动演奏者的音符。

一次同步选区成为一个内容线组。以后选中组内任一音符即可操作整组：点击未加入的演奏者
会增加同步，点击已加入的演奏者会取消同步；取消最后一位演奏者会删除组和链接，但保留
两侧可见谱面音符。同步组使用符头后方的半透明背景显示：同一和弦的符头合成圆角色块，
同一谱表行内相邻事件以较窄的 S 形色带相连；不同组按全局时间顺序稳定轮换低饱和色板，
不再改变音符本身颜色。缩谱插入音符后使用默认钢琴立即试听。

数据链为：

`缩谱音符 ← StorageReduction.links → 内容线`
`→ StoragePerformance → 演奏者`
`→ StorageStaffAssignment → 谱表`
`→ StorageOrchestration.links → 总谱书面音符`

两个方向建立的都是同一条链，缩谱从不直接绑定总谱谱表。以后换人或改谱表只编辑
performance / assignment，内容线与缩谱关系保持不变。

活动声部交互由共享 `VoiceFocus` 提供：它统一生成谱表声部按钮、非活动声部样式、
选区过滤、可选 section 和最终音符插入目标。分析/创作允许“全部声部”活动；再次点击当前
声部恢复全部。自由练习不复用这一跨整谱聚焦契约：它与主乐谱音符调板一样，在上方工具栏
选择谱表内部的 voice number，点击位置再决定具体 staff。后台分析声部由独立分离器派生，
不反向限制记谱编辑声部。

`VoiceFocus` 必须约束 renderer ghost 与提交的稳定 `TrackId`，不能只把其他声部变灰或过滤
选区，否则音符笔仍可能写入 `NoteToolState.activeVoiceNumber` 指向的另一声部。

## 双向编辑与同步

“视图”页的“分屏对照”显示当前缩谱；右侧缩谱与主谱使用相同的音符编辑器，可以插入、移调和移动休止符。两侧编辑进入主文档同一撤销栈。

提交边界沿两段链接传播明确修改：缩谱改音会先更新内容线，再更新总谱书面音符；
总谱改音则反向更新内容线和缩谱。两端同时变化、删除造成悬空或新增没有 link 时不猜测，
保留 `PITCH_DIVERGED`、`TIME_DIVERGED`、`DANGLING`、`UNMAPPED` 或 `UNREALIZED` 状态。

## 当前边界

当前版本暂不提供：分段创建缩谱、缩谱谱表行数随时间变化、多个缩谱切换、
performance / assignment 的多时间点区间编辑器、完整 `SECTION` 播放合成。这些功能
不改变当前 `StorageReduction` 与 `StorageOrchestration` 的兼容字段。
