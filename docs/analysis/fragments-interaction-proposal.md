# 缩谱层级与乐谱片段交互提案（第二版）

> 状态：**第一阶段已实现：分层数据、固定综合视图、演奏者标签与最小素材台流程已落地；
> 和声/曲式编辑、可调停靠和源片段联动仍为后续能力。**
>
> 本版核心调整：片段台只保存尚未确定 TimeCode 的零散素材；一旦内容的位置已经确定，
> 它就是缩谱某一层上的内容，直接在缩谱中编辑，不显示实例框，也不要求额外的放置管理。

## 1. 三个概念

### 1.1 缩谱

缩谱是与主谱共享时间轴的**层级容器**，不是一个待拼装的片段实例集合。它覆盖连续
TimeCode，可直接滚动、选择和编辑。

### 1.2 缩谱层

每一层表达创作或分析路径中的一种抽象：

| 层 | 内容 | 典型编辑方式 |
|----|------|--------------|
| 曲式层 | 段落、调性区域、终止位置 | 时间区间块 |
| 和声进行层 | 和弦、低音级数、功能 | 和弦时间轨 |
| 骨架层 | 声部进行、结构音 | 简化记谱 |
| 缩谱记谱层 | 旋律、对位、织体 | 普通乐谱编辑 |
| 配器实现层 | 演奏者、谱表与主谱映射 | 谱表/人员路由 |

这与 [composition.md](composition.md) 的“曲式 → 和声进行 → 缩谱 → 配器 → 总谱”
一致。和声进行不是缩谱旁边的附属面板，而是缩谱的一个正式层级。

### 1.3 乐谱片段

乐谱片段是**尚未确定作品 TimeCode**，或有意保留为可复用素材的音乐：

- 零散旋律；
- 动机及其变形；
- 和声块、节奏型、伴奏型；
- 从主谱/缩谱临时摘出的候选材料。

片段可分为：

| 类型 | 约束 |
|------|------|
| 普通片段 | 1–N 行谱表，可含多声部与和弦 |
| 旋律片段 | 单谱表、单声部、同一时刻最多一个音高 |

原“内容线”在概念上对应旋律片段，但不再要求用户先创建内容线才能编辑或配器。

## 2. 核心原则：确定 TimeCode 后直接编辑

若一段音乐已经有明确的目标小节和拍点：

- 它直接写入缩谱目标层；
- 使用缩谱本身的选区、插入、删除、复制、粘贴与拖动；
- 不显示“片段实例”边框；
- 不询问“修改源片段还是当前实例”；
- 不需要先经过片段台。

例如在主谱选择第 9–12 小节旋律并提取到缩谱时，结果直接出现在缩谱第 9–12 小节。
之后用户像编辑普通乐谱一样修改它。内部可以保留来源 link，但 UI 不额外暴露。

只有尚未决定放在作品何处的材料，才进入片段台。

## 3. 缩谱工作区

```text
┌─ 层级栏 ────────────────────────────────────────────────┐
│ [综合] [和声进行] [骨架] [缩谱记谱] [配器]       ＋层  │
├─────────────────────────────────────────────────────────┤
│ 和声： | I       | ii6 V7 | I       | ...              │
├─────────────────────────────────────────────────────────┤
│ 缩谱：     可直接编辑、与主谱 TimeCode 对齐的连续谱面   │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ 素材台（可折叠）：[主题 A] [节奏型] [动机 x]           │
└─────────────────────────────────────────────────────────┘
```

### 3.1 综合视图

“综合”是默认视图：

- 和声进行以紧凑轨显示在谱面上方；
- 曲式层显示更高层的区间带；
- 骨架或缩谱记谱使用实际谱表；
- 关闭的层不占空间；
- 播放头和水平滚动在所有层间共享。

用户看到的是同一条 TimeCode 上的多个抽象层，而不是在多个独立文档之间切换。

### 3.2 单层视图

点击层标签可专注编辑一层：

- 其他层淡化为上下文，或完全隐藏；
- 选择范围仍使用全局 TimeCode；
- 切回综合视图时不需要重新定位。

### 3.3 层级顺序

层按抽象程度从上到下排列，不使用任意 z-index：

`曲式 → 和声 → 骨架 → 缩谱记谱 → 配器实现`

用户可隐藏层，但第一版不允许任意重排，以保持不同作品间一致。

## 4. 直接编辑工作流

### 4.1 主谱 → 缩谱

1. 在主谱选择一段音乐；
2. 拖到缩谱的目标时间/谱表，或点击“提取到缩谱”；
3. 若原选区已有明确 TimeCode，默认保持原位置；
4. 内容直接写入当前缩谱记谱层；
5. 只有复音无法自动还原为目标声部时，才出现最小选择器。

不会自动在片段台创建卡片，也不打开内容线/演奏者表单。

### 4.2 在缩谱中创作

用户可直接：

- 在空白小节输入旋律；
- 复制、粘贴或拖动已有范围；
- 在和声层输入和弦进行；
- 对照和声层编写缩谱记谱层；
- 选中缩谱范围后实现到主谱。

这里的交互与普通谱面编辑一致，不需要“先创建片段再贴上去”。

### 4.3 缩谱 → 主谱

1. 选择缩谱记谱层的一段；
2. 拖到主谱目标谱表，纵向落点直接确定谱表；
3. 目标谱表只有一名演奏者时直接写入；
4. 有多名演奏者时显示紧凑编号选择器；
5. voice 自动选择，仅发生冲突时询问。

内容线、performance 与两段 link 可继续作为内部实现，但不成为主流程中的显式步骤。

## 5. 和声进行层

和声进行层第一版采用时间轨，而不是强制显示成五线谱：

- 每个和弦占一个 TimeCode 区间；
- 可拖左右边界调整时值；
- 双击输入和弦符号；
- 支持复制、粘贴和整体移调；
- 选中和弦范围后可创建骨架/缩谱写作任务；
- 缩谱音符可按当前和弦实时显示和弦音/外音。

若后续需要具体声部配置，可从和弦事件“展开为骨架层”，原和弦层仍保留。

## 6. 片段台

片段台不是当前缩谱编辑的必经步骤，默认折叠。它用于：

- 暂存还没决定位置的旋律和动机；
- 收藏会重复使用的素材；
- 对比多个候选版本；
- 从探索模式接收满意的候选；
- 跨缩谱或跨作品复用素材（远期）。

### 6.1 创建素材

- 把主谱/缩谱选区拖到片段台；
- 从片段台“＋”创建空白素材；
- 从探索结果选择“保存为片段”。

进入片段台时，素材的原始 TimeCode 只作为来源信息，不构成作品中的放置位置。

### 6.2 使用素材

从片段台拖到缩谱后：

- 预览目标 TimeCode 和谱表；
- 松手后音乐直接成为缩谱层内容；
- 默认不保留可见实例边框；
- 片段台中的素材继续保留，可再次使用；
- 内部记录 `sourceFragmentId`，供“查找来源”与批量更新等远期能力使用。

第一版不实现源素材与所有使用位置的实时联动，避免“编辑缩谱时先选择修改源还是实例”
这种额外交互。若以后确实需要联动，再加入显式的“链接放置”模式。

## 7. 建议的数据边界

```text
StorageReductionWorkspace
  id · title · timeRange
  layers: List<StorageReductionLayer>
  materialTray: List<StorageScoreFragment>

StorageReductionLayer
  id · kind(FORM/HARMONY/SKELETON/NOTATION/ORCHESTRATION)
  visible · content

StorageScoreFragment
  id · name · kind(NORMAL/MELODIC)
  score · sourceMetadata
```

- 缩谱层共享主谱 TimeCode，不各自维护互相漂移的时间轴。
- `NOTATION`/`SKELETON` 层可复用 `StorageScore`。
- `HARMONY` 层复用和弦轨事件，不强行转换成谱表。
- `FORM` 层复用区间标注。
- 片段本身无作品锚点；写入缩谱后成为层内容。
- 来源关系是可选元数据，不决定日常编辑行为。

## 8. 旧数据迁移

- 现有 `StorageReduction.score` 迁入默认 `NOTATION` 层。
- 已有缩谱与主谱 NoteLink 保留。
- `orchestration.lines` 可迁为隐藏的旋律来源记录；其音符直接呈现在对应缩谱/主谱位置。
- 旧文件打开后不要求用户理解或整理内容线。
- 待片段台实现时，用户可主动把某段内容“保存为素材”，不自动把所有旧内容线塞满片段台。

## 9. 撤销、播放与反馈

- 每次谱面/层编辑仍走主文档单一撤销栈。
- 所有可见层共享播放头、循环区和 TimeCode。
- 层的显示/隐藏是视图状态，不修改音乐。
- 从片段台写入缩谱是一次原子提交。
- 状态栏只报告音乐结果，例如“主题 A 已写入第 9–12 小节”。
- 主谱与缩谱不再打开绑定表单：框选一侧音符后，直接点击另一侧上方的演奏者或缩谱
  声部即完成同步。
- 缩谱初始允许所有声部操作；点击每个系统谱表行开头的声部按钮后，限制为该唯一声部，
  其他声部变灰；再次点击当前活动按钮恢复全部声部。总谱按活动演奏者过滤，非活动
  演奏者保持黑色。
- 演奏者与缩谱声部目标均采用两行标签：上行显示乐器/谱表名，下行显示演奏者编号或
  声部编号。
- 同步以隐藏内容线作为组身份：组内任一音符都可操作整组。点击未加入的演奏者会加入
  并实现，点击已加入的演奏者会取消；最后一位取消后删除同步组与链接。
- 同步状态不改变音符颜色，只在符头后显示半透明背景：和弦符头合为一个圆角色块，同组
  相邻事件在同一谱表行内以窄圆角曲线连接。不同组按时间顺序稳定轮换青、蓝、琥珀、
  紫、珊瑚、绿等低饱和颜色。
- 缩谱点击、拖动及插入音符均可试听；插入音符固定使用默认钢琴音色。
