# 减七和弦：省略根音的属九解释

> 状态：章节目录、单独练习、综合练习与自由求解器已接入。

## 1. 共享本体

`RootlessDominantNinthVocabulary` 把完全减七和弦解释为省略根音的属九和弦。每个
`RootlessDominantNinthType` 同时保存：

- 实际发声减七和弦的拼写根音；
- 从减七和弦某一音下降半音得到的省略属根音；
- 该属和弦所指向的调内目标音级；
- 被下降的减七和弦成员。

完全减七结构对称，所以同一发声音集可有多个功能解释。章节专用练习先按发声音集分成供用户
选择的三个“减七和弦”，再列出该音集能够指向的调内用法；不同用法保留不同 target identity，
不能只按 pitch class 集合去重。通用 `ChordSelectionCatalog` 当前仍会摊平这些解释，统一的
“音响—构造线路”选择投影尚待按
[和弦音响、多重解释与详情选择设计](../chord-detail-and-vagrant-chords.md) 接入。

例如 C 大调的 `♯2-♯4-6-1`：

- `♯2` 下降到 `2`，省略根音为 II，按 `V/V` 使用；
- `1` 下降到 `7`，省略根音为 VII，按 `V/III` 使用。

## 2. 声部进行

- 减七和弦作为省略根音的属九结构时，不要求不协和音预备。
- 所选“下降音”必须在同一声部进行到省略的属根音。
- 局部属导音仍使用副属章节共享的导音规则，上行到临时主音。
- 非转调用法中，减七和弦内相对当前调号的变化音必须以级进进入非变化音；允许同音名的
  半音还原，也允许相邻自然音级。
- 四个减七和弦音全部在场；普通七和弦的通用预备/解决规则不重复套用到该特殊身份。

上述会导致“永远写不出”的相邻对时，规则以 typed requirement 进入综合程序，再由禁忌表
生成器探测；枚举器只共享符号功能判定与必要的增量可达性检查。

## 3. 入口

- 单独练习：先选减七和弦，再选一个调内功能解释，最后选对应解决进行。
- 综合练习：在副属阶段之后以唯一的通用入口
  `schoenberg.integrated.diminished-seventh` 加入减七和弦词汇与
  `DIMINISHED_SEVENTH` 知识标签；大小调由同一入口内的调性选择器决定，不拆成两个阶段。
- 自由求解器：`DiatonicChordVocabulary.forContext` 通过显式开关加入同一目录；
  `FreeHarmonyRuleProvider` 将变化音级进与局部属导音作为可覆盖软偏好。
- 自由练习：减七不进入默认短进行清单；选中具体减七解释后，章节贡献其省根属九用法对应的
  属功能解决。相同发声音集的不同 usage 以精确 `ChordInterpretationRef` 查询，不能互相吞并。
