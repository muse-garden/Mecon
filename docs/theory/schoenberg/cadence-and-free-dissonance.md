# 终止式与自由处理七和弦 / 导和弦

本文定义 `schoenberg.cadence` 与
`schoenberg.freer-seventh-leading` 两个连续阶段。两者挂在大小调通用分支，并继承根音方向、
反复和一般四部写作规则。

## 1. 终止式策略

终止式不是枚举器末尾临时拼接的字符串，而是一份不可变的符号序列策略。枚举前缀剪枝与
运行时 `Constraint` 都委托同一个策略判定。

正格终止的末尾结构为：

- `(IV | ii | VI) - V - I`；
- V 必须原位，可为三和弦或七和弦；
- 小调 V 必须是含升高导音的属大三和弦或属七和弦，不能使用自然小调的 v 小三和弦；
- 末尾 I 必须为原位三和弦；
- 前属和弦可为三 / 七和弦及允许的转位，但三和弦不用第二转位；
- 开启终止四六后变为 `(IV | ii | VI) - I64 - V - I`。

开启阻碍终止后，全曲在最终正格终止之前还必须出现一次原位 `V/V7 - VI` 或
`V/V7 - IV`。阻碍终止只延缓闭合，不能取代最后的正格终止。
若属和弦的导音 `7` 位于外声部，该声部必须上行级进到 `1`；内声部导音仍按该
章节的自由声部处理，以保留阻碍终止的外声部期待感。

上一章的类似和弦 / 类似进行反复规则继续约束终止式之前的正文。终止式固定槽位是结构性例外：
例如 `I64-V-I` 中相距很近的两个 I 不按无意反复处理；运行时用正文窗口约束，枚举前缀使用同一
终止式槽位边界。

## 2. 规则档位

`STRICT` 用于旧章节：七音和减五度维持原有硬预备 / 解决与禁重复规则。

`CADENTIAL` 只增加终止式所需的例外：

- 原位 V7 可以不预备；
- `V7-VI` 的七音仍以下行解决为常态；
- `V7-IV` 允许七音保留为共同音。

`FREER` 用于新章节及后续章节：

- 七音可由级进的经过运动引入，不再以“前一和弦必须含该音”作符号层硬门槛；
- 七音的级进解决保留为可解释偏好与 finding；
- 减和弦的减五度预备、解决和禁重复由硬规则降为旋律偏好；
- 小调增二度、导音解决和一般声部进行仍是硬规则。

早期 target/frame 关系剪枝只能投影外层模态为 `Require` 的 typed 邻接规则。
`Prefer / Annotate` 即使携带同一个 requirement，也只能进入评分与 finding，不能提前删掉
`I64 - V7` 这类终止档明确允许的进行。

档位只向后生效，不修改旧练习的结果。

## 3. 自由导和弦

自由阶段把导和弦解释为省略根音的 V7：

- 新引入的替代用法限于 `VII6`，可接 `I / VI / IV / ii`；
- 已学习的 `VII-III` 继续有效；
- 根位与第二转位不作为新自由用法的常规候选；
- 自由练习至少包含一次上述 `VII6` 替代连接，避免只重复旧材料。

自由练习同时开启阻碍终止时，正文必须容纳两个互不重叠的相邻事件：
`V/V7 - VI/IV` 与 `VII6 - I/VI/IV/ii`。枚举器在每个前缀上计算完成尚缺事件所需的
最少正文槽位；剩余槽位不足时立即剪枝，而不是等完整序列才检查。这样默认预算用于仍可能
完成教学结构的分支，不靠扩大预算或调整候选排序寻找结果。

小调 `ii° / vi° / vii°` 的减五度采用同一“旋律可解释”档位；其具体根音去向仍由共享的
根音方向策略决定，不另写一套固定目标表。

## 4. 禁忌相邻进行

严格档与自由档分开探测和读取禁忌表。自由档只能从其自身 program 投影 typed 硬规则生成，
不得复用包含严格七音 / 减五度规则的旧表，也不得在枚举器中写死例外。

资源命名：

- `forbidden-transitions[-minor].txt`：严格档；
- `forbidden-transitions-free[-minor].txt`：自由档。

任何 typed 规则变更后都要通过独立的
`:theory:schoenbergForbiddenTransitionTest` 任务重刷对应表并运行时效守卫；该穷举任务不进入日常
`:theory:jvmTest`。

自由档重刷：

```
./gradlew.bat :theory:schoenbergForbiddenTransitionTest --tests "*SchoenbergFreeForbiddenTransitionGenerator*" -Pschoenberg.forbidden.write=true
```

## 5. 探索请求

终止式及后续练习暴露两个布尔选项：

- `includeDeceptiveCadence`；
- `includeCadentialSixFour`。

两个选项必须同时传给枚举与求解 program；已选定的外部进行也须经过相同硬约束，不能绕过。
界面进入终止式练习或切换上述选项时默认选择“任意进行”，由运行时在本次枚举的完整候选池中
寻找首个可写的四部实现；用户明确选定某条进行后，仍只检验该进行。这样终止四六不会因枚举排序
前若干条恰好无解而误报“无解”。
