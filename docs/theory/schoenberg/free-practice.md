## 1. 状态与事务

`RuntimeScore` 是音符、休止、连线和谱表的音乐材料真相；可序列化
`HarmonyWorkspaceState` 保存稳定槽、可重叠调性布局、逐槽调性读法、枢纽标记和惯用进行实例。
和弦事件与调性区域由工作区单向投影到谱面插件轨。工作区不保存第二份自由音符列表。

两者通过一次 `HarmonyPracticeTransaction` 原子提交到 `ScoreStateManager`，保证一次操作
只产生一个撤销项。宿主对 UI 发布单个不可变 `HarmonyPracticeFrame`，undo/redo 同时恢复
谱面与计划。

自由练习使用创建时确定的 `VoicePlan`：

- 声部数 `N` 可配置，沿用 `VoiceSpec` 的稳定 voice id、次序、边界与音域；
- 一次练习内所有声部持续参与，不支持中途动态加入或退出；
- 四声部 SATB 只是默认 preset；
- 完整性与省略规则按参与和弦配置的声部数计算，和弦外持续音不占成员名额；
- UI、钢琴卷轴、检查与自动声部写作按 `VoicePlan` 枚举，不写死 SATB 四列。

同时创建 `VoiceNotationPlan`，记录 voice → staff / voice number / clef / stem 的稳定映射。
三至六声部使用同一个通用装配器；四声部 SATB 装配器也委托该实现。

## 2. 和弦编辑命令

`HarmonyWorkspaceEditor.applyResult` 是所有工作区命令的失败边界。命令校验失败时返回原
`HarmonyWorkspaceState` 引用和可展示的 `errorMessage`，宿主不得提交 score/workspace
事务；工作台在顶部展示错误。拖拽预览使用同一边界，失败时丢弃草稿并恢复手势开始前状态。
`apply` 是兼容入口，同样返回原状态，并可通过 `onError` 接收错误信息。

- `InsertChord(SPLIT_SPAN)`：细分当前和弦时段，不移动音符；
- `InsertChord(RIPPLE, duration)`：插入时间并顺延后续和弦与音符；
- `DeleteChord(SYMBOL_ONLY)`：仅删记号，前一和弦时段自然延长；
- `DeleteChord(RIPPLE_SPAN)`：删该时段音符并把后续材料前移；
- `ReplaceChord`：保持时间范围，仅换功能解释 / 和弦。
- 新建自由练习只创建一个主和弦（大调 `I`、小调 `i`）；后续时段由用户在时间轴空隙或
  尾部的 `+` 入口创建。
- `PlaceChordRange` 直接设置一个和弦的起止位置。新区间覆盖其他和弦时，被覆盖和弦实时
  裁短或移除；移开后允许留下空隙。拖动相邻且无空隙的公共边界时，用
  `MoveSharedBoundary` 同时改写两侧范围。
- `TranslateChordRange` 平移单个和弦；按住 Ctrl 时将该和弦及其右侧全部和弦作为一个组
  平移，组内间距保持不变。时间不得早于谱首，所有交互吸附到用户选择的四分至六十四分
  音符网格。
- 拖动预览只保存在时间轴控件的本地草稿中，不写入工作区或宿主；鼠标松开时才把最终状态提交给
  `HarmonyPracticeTransaction`；一次按下—拖动—松开恰好对应一个撤销项。
- Ctrl 拖动边界使用 `MoveBoundaryWithFollowing`：改变该边界并整体平移右侧和弦，保持
  右侧各和弦的时值与间距。删除和弦用 `RemoveChordRange` 留出空隙；工作区最后一个槽只
  清空和弦内容，以维持可编辑的初始锚点。

时间轴按绝对谱时定位而不是按列表等分。每个四分音符拍使用稳定像素宽度，新增和弦只扩展
画布，不重新均分既有时段；鼠标滚轮以较快步进缩放拍宽，长序列使用显式横向滚动条。时间轴显示
1-based 小节编号，吸附网格可在四分、八分、十六分、三十二分与六十四分音符间切换。
和弦框内显示共享和弦目录的 `functionalSymbol` 及构成音，并与选择器共用相对/绝对音高
模式。待选择和弦、已选择和弦与带 `+` 的空隙使用不同
底色。框下使用线条、拍点与小节强拍图形表达节拍，不显示 `1.1` 一类文字。

和弦框左右边缘和中部分别提供缩放、平移命中区。无缝相邻处保留三个清晰命中带：边界左侧
只缩放左和弦、中央高亮手柄联动两侧、边界右侧只缩放右和弦；有空隙时在空隙中央显示 `+`
并插入一个覆盖完整空隙的空和弦。删除入口位于和声选择的当前和弦按钮组，仅在槽可删除时显示；
时间轴仍支持 Delete 键。旧的
“细分拍点 / 插入并顺延 / 仅清除记号 / 删除时段并前移”按钮不再作为主交互。

选择状态保存稳定 `WorkspaceSlotId`，不能保存易失的列表下标；插入、覆盖裁剪、删除及
undo/redo 恢复后再把 id 投影为当前下标。单边手柄悬停/拖动显示橙色，公共双边手柄显示
蓝色；拖动时只有当前命中的边界高亮，左右调整光标在指针离开命中区后仍保持到拖动结束，
同时显示当前“单边边界 / 双边公共边界 / 平移和弦”操作标签。

时间波纹使用纯函数时间变换与插件事件适配器，覆盖 voice/pitch、和弦、调性区间及相关锚点，
完成后统一 compute、render 和 undo；不能实现为 Compose 列表移动。

### 调性布局、枢纽与惯用进行

- 初始调性的基线左端固定在谱首、右端可拖动，开放结尾仍随时间轴扩展，且基线不可删除；
- 每条调性线的标签同时显示绝对调名、主音相对初始调的音级，以及带正负号的最短五度圈距离；
  前两者与五度圈相对模式共用 `ModulationPitchLabels.relativeTonicLabel`，距离统一调用
  `ModulationCircleOfFifths.signedDistanceLabel`；
- 点击拍点插入从该点到末尾的调性线；拖选拍点范围后插入有限调性线。两者使用
  `desktop-ui-kit` 的紧凑五度圈弹出菜单，并默认终止之前调性；旧线延续至当前和弦末端，
  因而新旧调性在该和弦上保持重叠，也可取消终止以保留完整重叠；
- 非基线线条的左右端点可拖动。右栏顶部只显示当前和弦所选调性，点击后用同一五度圈菜单修改，
  也可直接在当前和弦插入调性线；
- 重合区按所选调性目录选和弦；同一响度在其他活动调性中的功能解释按构成音匹配，时间轴卡片
  用不同底色在单行列出各调的功能与相对音级，右侧继续展示完整定义；
- 多调均有定义的候选在和弦目录用调性重合色和“另 N 调”标识；
- 枢纽和弦只是 `WorkspaceHarmonySlot.isPivotChord` 展示标记，不增加求解约束。多调性重叠区会在
  和声选择最前面显示“转调枢纽和弦推荐”：相差 1–2 个升降号使用公共自然音和弦；相差 3–4 个
  升号使用前调 `3–♯5–7`，相差 3–4 个降号使用后调 `3–♯5–7`；
- 惯用进行以 `WorkspaceIdiomInstance` 整组插入，时间轴显示来源样式并禁止逐槽替换、移动或删除；
- 多调性重叠区同时横向展示每条调性下同一实际音响的功能符号与构成音；展示顺序按覆盖该和弦的
  实体或派生调性线起点排序，不沿用 `primary/alternates` 的存储顺序。切换“按哪个调选和弦”只
  改变读法与目录筛选，不改写已保存的实际音高集合。惯用进行目录随所选调性读法切换，新调性
  单独覆盖的区域不继续显示旧调性的目录内容；
  变体切换与删除只能以实例级命令执行。`slotIds` 是成员关系真相，精确解释、低音与时间兼容的
  两个实例可共享中间槽；删除实例只解除成员关系和编辑锁定，时间轴上的和弦槽及五线谱材料均保留。
  重叠标记自动分轨，点击共享槽或标记可分别选择相关实例。

自由练习不维护教材和声序列。`SchoenbergFreePracticeCatalog` 遍历
`SchoenbergChapterRegistry.exerciseRegistrations`，调用章节 handler 的可选贡献入口：
终止式后缀、副属/副导/调式色彩、减七、拿坡里/类拿坡里和增六解决均由对应章节贡献。原
“远关系转调与属持续音”目录项已经移除：四个以内升降号的转调改由多调性和声选择中的枢纽推荐
承担；属持续音复用远关系转调章节的 `V–VI–V` 确认窗口，作为“属持续音（增强转调目标调性）”
独立惯用进行，可在任意被相应调性线覆盖的位置插入。目录步骤
保存精确解释、低音、时值与 anchor；解释引用必须使用与 `ChordSelectionCatalog`、窗口求解器相同的
`chord-selection` tonal-context lens 生成，桌面不再反查显示字符串。默认目录含 `V–I`、`V–vi/iv`、
`ii/IV–(I64)–V–I`、`ii/IV–(I64)–V`、`V/V–(I64)–V`、`N6–(I64)–V` 与三族
`+6–(I64)–V`。选中和弦时后台另查“与当前和弦相关”，并保留“全部教材进行”。新增教材材料
须由章节 handler 贡献，禁止在桌面自由练习增加 exercise-id 白名单。

惯用进行的目录变体携带教材常用低音。新建步骤以该低音作为初值；共享步骤当前为“任意”时也采用
该初值，已有明确低音则保留用户选择。只有正格终止最后的 `I/i` 与终止四六 `I64` 属结构锁定，
其他步骤的常用低音仅是可修改的初值，不参与重叠共享冲突判定。拿坡里、增六的常用低音说明与
"终止式 V 不建议使用二转位"均由目录变体声明；选中对应进行步骤时在低音选择器下展示，低音
选择器本身不根据当前低音自行推断这些章节提示。

目录中的普通三和弦步骤会从同一章节词汇投影七和弦选项；终止四六和正格终止末尾的 I/i 不替换。
因此属前、阻碍终止、副属、拿坡里与增六目标均可显示合法的七和弦组合。半减七增六到拿坡里的
等音连接作为默认惯用进行保留。打开“展示离调”后，后台只枚举一次大小调关系模板，再投影到目标调；
它只扩展“与当前和弦相关”，不扩展“全部教材进行”，且不重复投影本已带离调含义的副属/副导进行。
`ø+6`/半减七、Fr+6 的对称目标、减七与调式增三通过可听音响 focus 互相发现。Ger+6 则无须打开
离调开关：选择德国增六后，目录自动复用与其等音的目标调主属七惯用进行，并用本调身份重标记为
`Ger+6–♭II` 等线路；不存在单独的 Ger+6–拿坡里特例定义。仅在离调开关打开时，每个变体展示目标调
和相对初始调的最短升/降号距离，面板可按目标调筛选；同一可听音响、低音与时值的进行只保留调号
偏离最少者，并在“相关/全部”和不同定义之间只显示一次。“视作”关系会逐步查询当前调的精确解释，
目标和弦也可识别为拿坡里等变化音和弦；若整条进行均可重解释，就使用当前调性线与当前调解释插入，
同时保存原调解释以投影原章节教学规则。仅不能完整重解释的原目标调变体仍要求目标调性线覆盖范围。

### ⚠️ 目录构建的性能契约

选中 Ger+6 一类游移和弦会**在交互路径上**即时构建离调目录（30 个目标调），因此三条纯函数
必须保持记忆化，不得改回逐次重算：

- `SchoenbergSymbolicChord.toTarget(triads)`：`SchoenbergChordCatalog.targets` 每次调用都收集整套
  目录，而枚举与相邻剪枝对同一 (调, 和弦) 反复求值上千次；按 (调, 和弦) 记忆化。
- `SchoenbergSecondaryDominantChapter.enumerate/harmonyChoices`：**记忆化按 choice 切分保留**，
  不得合并成一次全量枚举——逐 choice 的去重与 `MAX_ENUMERATED_PROGRESSIONS` 截断语义与全量不同。
- `ChordSelectionCatalog.groups(key, providers)`：离调投影一次要 30 个调的目录。

后备 map 由 `theoryMemoMap()` 提供：JVM 用 `ConcurrentHashMap`（桌面在后台 dispatcher 上并发
构建两份目录），JS 单线程用普通 map。投影时的和弦查表按 12 位音级掩码索引
（`SoundingChoiceIndex`）：和弦是 12 等分圆上的掩码，移调即旋转，故查表是位旋转 + 哈希而非线性
扫描；分组保持目录原顺序，候选列表与线性扫描逐项相等（`SoundingChoiceIndexTest` 锁定）。

## 3. 钢琴卷轴与拼写

- 五线谱直接使用 `RenderedScoreView`，不保留自由练习专用 Canvas 预览；
- 钢琴卷轴使用主界面 `PianoRollSurface`，只通过可选 interaction config 增加编辑；
- 和弦音模式点击背景输入；新音与已有音高拖动都按当前 chord span 吸附到最近和弦音；
- 自由绘制不响应单击插音：在目标音高行横向拖出范围，左右端按上方工具栏的“自动吸附单位”吸附；
- 上方工具栏的“自动吸附单位”是和声时间轴与卷轴共享的唯一网格状态；自由绘制模式下按住 Ctrl
  拖动改为平移卷轴，不创建音符；
- 卷轴不重复绘制顶部和弦文字轨；全局对齐轴已经表达和弦边界，只保留和弦音高亮背景；
- 已有音符可按半音纵向拖动；拖左右端点调整范围。和弦事件整体改范围，共享边界会同步调整
  同一记谱声部的相邻音符，一次手势只提交一个撤销项；
- 自动记谱在全部不重叠的默认通道间按音域和连续性选择，不因首个和弦音先落入某谱表就把
  后续音全部堆入该谱表；一段连续绘制的网格音符优先保持同一通道；
- 自由绘制先决定 MIDI 与时间，再由活动 `TonalContext` 和
  `ChordInterpretation.spellingFor` 给出首选拼写；
- 多种功能拼写保留候选，不统一使用 `preferSharps=true`；
- 五线谱读取已存储的正确 `Pitch`，由 Computed 层生成临时记号。

钢琴卷轴消费后台不可变帧；点击命中只查询可见 chord span，不在指针回调全谱扫描。

五线谱与钢琴卷轴共享同一个 selection、active voice、`NoteInsertionPolicy` 和编辑事务。
任何一侧的修改必须立即在另一侧出现，并且只产生一个撤销项。

五线谱复用公共 `HorizontalScoreEditor`，把选择、框选、音符输入与编辑按钮平铺在谱面上方，
并按可用宽度自动换行；自由练习不开放乐谱元素笔。
工具栏内使用与主界面音符调板完全相同的 1–4 编号声部按钮，不使用缩谱式谱表行首按钮。编号作用
于每一个谱表：点击位置决定 staff，编号决定该 staff 内的 voice number；分析声部仍由
`AnalyticalVoiceSeparator` 独立派生。音符输入后保留的选区不触发声部移动；`NOTE` 模式切换
编号只设置后续输入，选择/框选模式才编辑已有音符。卷轴选中音符后，Delete 将同一共享选区替换为休止符；
再点击某个声部时，该音符与目标声部同一时点的音符交换。Esc 统一退出输入笔、清空五线谱
与卷轴选区，并把卷轴输入声部恢复为“全部”。五线谱拖动音符移调或调整休止符位置必须通过
`HarmonyPracticeScoreHost` 提交，禁止只保留 `RenderedScoreView` 的本地拖动预览；提交后
钢琴卷轴读取同一新帧，并产生一个可撤销历史项。
音符选区的时值、附点、升降号、连音线、连音符、符杠、演奏法与声部编辑必须复用主页面的
`ScoreSelectionEditor`，调板按钮和快捷键消费同一个实例；自由练习只提供
`HarmonyPracticeScoreHost` 的事务提交实现，不复制选区投影与属性切换规则。关闭谱面本地
pan 只表示水平视口由工作台时间轴管理，不得同时关闭音符/休止符的直接拖动。
上方工具栏集中承载自动求解/自由练习切换、自动吸附单位、和弦默认拍数与写作设置；五线谱画布、和声时间轴和钢琴卷轴共享同一水平坐标原点，不保留旧左侧工具栏的
空白 gutter；嵌入式谱面隐藏“主乐谱视图”和缩放百分比角标，并使用紧凑首系统缩进。
写作区使用无 Card 的平面布局，以左右竖向分隔线划定编辑区域，钢琴卷轴上方使用完整横向分隔线。
右侧规划栏与五线谱/钢琴卷轴分隔条采用延迟提交：拖动时固定指针命中层，按原始指针位移绘制
“完整分隔线 + 半透明面板阴影”，松开后一次提交最终宽高，避免重排热路径和预览落后鼠标。

和声时间轴跨过当前谱尾时，工作台在后台先扩展 `RuntimeScore` 的 2/4 小节结构并重新
compute，再与工作区作为同一事务发布；五线谱、卷轴和和声 span 因而始终覆盖同一绝对时域。
卷轴量化以每小节起点重新建立网格，附点等不能整除 2/4 的时值不会把后续小节的落点整体移位。
卷轴输入以当前 `RuntimeScore` 已声明小节的谱尾为硬边界；量化后的起点位于谱尾、或完整时值
会越过谱尾时拒绝输入。和声时间轴扩展并发布新小节后，对应卷轴区间才变为可写。

## 4. 活动声部与单音约束

自由练习没有跨整谱活动声部。`NoteToolState.activeVoiceNumber` 与主编辑器一样只表示谱表内
声部编号；renderer ghost 与提交均按“命中的 staff + voice number”解析目标。后台分析声部
独立派生，不参与记谱声部选择。

每个自由练习声部是单音线，使用 core 的 `NoteInsertionPolicy.MONODIC`：

- 空位置正常插入单音；
- 已有音符起点改写该事件音高，保留事件 ID、原时值与记谱属性；
- 异常旧和弦在一次改写后收敛为单音；
- 多音 MIDI/键盘批次与含和弦粘贴显式拒绝，不静默取其中一个音。

主编辑器继续使用默认 `CHORDAL` 策略，同起点叠音仍生成和弦。

## 5. 检查、完成度与自动写作

`HarmonyWorkspaceProjector` 把谱面投影为和声槽与表面声部：

- pattern 自动机给出关键进行完成度；
- figuration reduction 还原骨架并分类和弦外音；
- 已有规则产出与自动求解相同的 hint / warning；
- 缺失材料保持 `UNDETERMINED`，不把半成品误报为违规；
- finding 锚到真实和弦 / 音符 `EventId`。

自由练习检查与自动求解复用同一个 `ConstraintProgram`、rule provider 和评分入口，UI 侧不再自行
实现平行纯五/八度这类声部规则。完整声部分离成功后，已写谱面作为 observed frames 进入
`ConstraintProgramSolver.checkObserved`，返回的 `RuleFinding` 保留 hard / soft / hint 严重度，并将
求解器锚点映射回真实音符 `EventId`。声部分离未完成时不追加这类推断，避免误报半成品或交叠织体。

`checkObserved` 覆盖求解器拒绝的两层：符号层按已选和弦重跑 target-only 硬规则预检，声部层由同一批
rule provider 评分。**但求解器以候选域（而非规则）表达的限制不会产生 finding**——声部音域与声部交叉
只存在于 `ChordTargetCandidateFactory` 的枚举里，因此仍由工作区自己的音域检查覆盖；新增这类域级限制时
必须同步决定由谁报告，不能默认 check 会看见。

该检查会为每段连续已写区间编译一次 program 并跑全规则评分，属于后台任务：调用方必须防抖并传入
可取消的 `SearchCancellation`（桌面端由 `produceState` 的 job 驱动），不得在每次击键时同步运行。

自动写作只为用户已经选择的和弦填充具体声部，不再生成未来和弦。自动触发、向左回溯、
选段重写、换结果、单步撤销和有界回放统一由
[自动声部写作改造](../../exploration/free-practice-auto-writing.md) 定义；求解窗口、可行性剪枝与
`refine` 分期见 [窗口写作设计](../free-practice-window-voicing.md)。

惯用进行插入/替换使用实例的完整槽集合做一次显式写作 scope；左边界实际音高必须属于当前槽
允许的目标域，求解结果也逐槽校验 target identity。因此覆盖旧 I 插入 `V–I` 时，旧 I 不会再被
误当作 V 的可用边界，整组写作与 workspace 在同一事务中提交。

## 6. 实施与验收

1. **共享宿主**：RuntimeScore 真相、默认 renderer、共享钢琴卷轴与 active voice。
2. **单音编辑**：两种输入、上下文拼写、MONODIC 策略与原子撤销。
3. **调性布局**：自由配置重叠调性线、跨调解释与可选枢纽标记。
4. **惯用进行**：章节自动发现、精确步骤、focus/anchor、重叠整组插入与实例级调整。
5. **自动写作**：固定用户和弦目标，显式复合 scope 生成/重写范围内的声部实现。

验收覆盖：

- split/ripple 插删同步变换和弦、音符、调性区间，单步 undo/redo 可逆；
- 区间缩放、平移、公共边界与 Ctrl 组平移均保持时段有序、正时值且互不重叠；
- 空隙 `+` 精确填满空隙，时间轴文字与共享和弦选择目录一致；
- 三、四及更多固定声部 preset 均无 SATB 硬编码；
- G♯/A♭ 等拼写按 lens 保存，Computed 临时记号正确；
- 同一声部任何 Runtime pitch event 都至多一个音高，主编辑器和弦行为不回退；
- 五线谱与卷轴编辑、选区、活动声部及撤销状态同步；
- 半成品检查不把未知当违规；
- 自动写作不选择未来和弦；中段自动触发不改之后材料，换结果返回同范围的不同声部实现。

实现入口：

- `theory/.../freepractice/HarmonyWorkspace.kt`：可序列化状态、split/ripple 命令与三值完成度；
- `HarmonyPracticeTransaction.kt`：工作区与谱面单步 undo/redo；
- `HarmonyContinuationSearch.kt`：现有未接线的旧续写门面；自动写作落地时删除。
- `SchoenbergFreePracticeCatalog.kt`：从章节注册表聚合枢纽定义与可插入惯用进行；
- `apps/desktop/.../exploration/FreePracticeWorkbench.kt`：调性布局、惯用进行、和声时间轴、
  同步谱表预览、可编辑钢琴卷轴与提示；自动写作工具栏按新设计接入。

## 输入面板与历史

工作台复用主编辑器的 `NotePalette`、`NoteToolState` 与 `handleEditingShortcut`。五线谱和钢琴卷轴
都读取当前时值、附点、休止、连音组、符杠与奏法设置；钢琴卷轴按所选时值量化。共享
undo/redo 同时恢复 `RuntimeScore` 与和声工作区，纯工作区提交也必须发布新的宿主版本。

## 初始调性与和弦目录

自由练习创建前可从完整大小调五度圈选择初始调性。改变初始调性会用新调号重建练习谱面，
并创建一条默认开放到末尾的初始调性基线；后续可收束其右端，其他调性全部来自工作区的
`WorkspaceTonalLayout`。

和弦选择不维护 UI 内的符号白名单。各乐理章节用
`@DiscoverableChordCatalogChapter` 和 `ChordCatalogContribution` 声明自身类别、顺序、
i18n key、构造来源与功能符号投影；JVM 通过反射发现后由共享 `ChordSelectionCatalog`
聚合。现包括自然音三/七和弦、副属、副导、调式增三、其他调式色彩及省略根音属九功能的
减七和弦。完整接入协议见
[../chord-catalog-contributions.md](../chord-catalog-contributions.md)。

每个候选同时显示功能符号与按结构成员顺序排列的和弦音。和弦音可在保留拼写的绝对音名
和相对调号大调主音的音级之间切换（A 小调 `i` 为 `6–1–3`）。通用
`desktop-ui-kit/ChordCatalogPicker` 展开时限高滚动，也可整体折叠，为谱面和钢琴卷轴
释放垂直空间。钢琴卷轴高亮同样查询该目录，不再另写一份罗马数字解析器；高亮与选择器都读取
槽保存的调性布局 id，旧 v1 工作区在打开时先补初始调性基线，不能按槽序号推测转调边界。
每个分类由共享目录按规范显示根音的 pitch class 升序排列；增三、减七等对称游移和弦按各自
family 的可听音响聚合，重复构造只增加解释线路，不增加重复卡片。

小调自然音三和弦与七和弦候选都使用自然、和声、上行旋律小调的并集，而不是只读取
AEOLIAN 七音。因此同一类别会同时提供未升高与含 `♯4` / `♯5` 的变体；三和弦来源复用
`NaturalTriads`，七和弦则分别在三种小调音阶上叠置三度并按实际音响去重，其构成音仍相对
调号显示。教材综合练习对冲突七音的阶段性过滤只约束该练习，不缩减自由练习目录。
