# 在调性的边缘

本章接入 `textbook-schonberg.md` 的“在调性的边缘”，实现游移和弦标记、意大利/德国/法国
增六和弦，以及大二度关系的 `ø+6` 增六重释。实现入口：

- `constraint/AugmentedSixthVocabulary.kt`：拼写敏感的构造与功能解释；
- `schoenberg/SchoenbergAugmentedSixthChapter.kt`：独立练习、连接枚举与 typed 规则；
- `SchoenbergIntegratedVocabulary` / `SchoenbergIntegratedProgramBuilder`：统一综合练习入口。

## 游移和弦

增三与减七解释现在同时携带 `schoenberg.vagrant-chord` treatment 和 `vagrant-chord` tag。
这表示它们可作为对称音响获得自由解释；既有副属、根音省略属九解释仍保留，未被自由解释替换。
综合求解中，明确选择的功能解释继续应用其 typed 倾向音规则。

## 增六词汇

每个调内目标音级均生成三类解释；指向属音时显示 `It+6`、`Ger+6`、`Fr+6`，指向其他
音级时追加目标罗马数字，例如指向 VII 的意大利增六显示 `It+6/VII`：

| 类别 | 指向属音时的 C 大调拼写 | 构造来源 |
|---|---|---|
| It+6 | `F♯–A♭–C` | 重属七省根后将 6 降为 ♭6 |
| Ger+6 | `F♯–A♭–C–E♭` | 重属降九省根减七后将 6 降为 ♭6 |
| Fr+6 | `D–F♯–A♭–C` | ii7 的三音升半音、五音降半音 |

`ChordDefinition` 保留音名与变化记号，因此 Ger+6 与等音属七不会合并成同一拼写身份。
三音 It+6 暴露三个转位，四音 Ger+6 / Fr+6 暴露四个转位；各副属目标复用同一构造算法。

半减七的大二度外音还可重释为增六两端，并显示为 `ø+6`。它拥有独立 family、interpretation、
选择卡片和连接规则，不与普通 `iiø7` 合并；两者即使音响相同，也按两种和弦解释参与练习。

自由练习的和弦详情使用 typed `AugmentedSixthDerivation` 生成乐谱示意：依次显示构造基底、
增六拼写和共同解决音。增六事件保持 `♭6` 在最低、`♯4` 在最高；It/Ger 的第一事件显示省根
副属七/九的虚拟根音，虚拟根置于最下方并灰显，实际减三/减七成员重排后与第二事件逐声部对齐；
Fr 的 ii7 来源同样只重排第一事件。第三事件用目标音的两个八度表示上下两端分别到达。
`ø+6` 的构造来源与增六音响相同时只画一次。
构造谱例中的每个和弦使用独立的临时记号上下文；相同升降号不得因前一个和弦已经出现而
在后续和弦中省略。
展开线路另由同一 DTO 生成“来源公式 → 省根中间结果 → 半音变化 → 增六公式”的文字过程，
线路标题保持原有 family 标题。UI 只消费中性的音高 DTO，不从 It/Ger/Fr/ø 标题反推音高。
It/Ger 的副属来源对全部七个目标统一按“大小七和弦，再在七音上叠加小三度”构造，不从原调
直接补齐音级；因此 C 大调的 `V9/VII` 必须拼为 `#4-#6-#1-3-5`，再将 `#1` 降为 `1`。

自由练习目录把增六按目标音级排序，同一目标内按 It、Ger、Fr 排列，因此指向 VII 的解释位于
其他目标之后。类别顺序为：拿坡里 → 指向 V 的增六 → 小下属关系 → 其他增六；前两组集中呈现
清晰属前功能，其他带离调/游移特性的增六解释置后。

## 连接规则

硬规则只表达教材明确的增六两端汇聚：升方邻音上行半音、降方邻音下行半音到同一目标音。
规则使用 `ChordToneNeighborRequirement`，所以独立练习、综合求解和禁忌相邻探测能共享语义。

枚举层提供：

- 所有三类增六到其功能目标；
- Ger+6 到对应局部 vi / iv 的阻碍进行；
- 大调中的 `ø+6 → N`，将半减七音响的根音与七音之大二度重释为增六；普通 `iiø7` 的一般
  进行仍属于小下属关系词汇。

其他内声部只受一般四部写作和平顺性约束，不从教材未明确的例子推导新硬规则。

## 课程入口

- 独立练习：`schoenberg.augmented-sixth`；
- 累计综合练习：`schoenberg.integrated.augmented-sixth`。

综合练习只有一个 exercise/rule id，挂在 `GENERAL_BRANCH_RULE_ID`；大调和小调通过 `Key.mode`
进入同一入口。累计 treatment 包含调内和弦、副属、减七、游移解释与增六词汇。

## 后续整理

连接的功能清晰度排序仍未进入公共 scoring policy。目前保留了可追溯的功能目标、family、treatment
和连接种类，后续可在不重写词汇或求解规则的前提下增加“明确功能 → 模糊功能 → 装饰性进行”的排序。
