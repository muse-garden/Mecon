# 副属和弦与副导和弦

> 状态：章节枚举、四部求解、自由求解器词汇与桌面进行显示已接入。

## 1. 单一本体

`SecondaryHarmonyVocabulary` 是和声类型列表、勋伯格章节和自由求解器共用的不可变目录。
每个 `SecondaryHarmonyType` 保存：

- 功能族：副属、副导、调式增三和弦、Dorian/Lydian 下行属和弦；
- 临时主音音级与根音的自然音级/变化量；
- 三和弦或七和弦性质；
- 产生该类型的中古调式来源。

具体和弦先构造为 `ConstructedChord`，按拼写音集合归入 `ChordCatalog`，再把每种功能解释与转位
展开为 `InterpretedChordTarget`。
`SchoenbergSymbolicChord` 只镜像这些功能字段，不另算一份音高。

## 2. 中古调式派生

目录对每个自然音级建立对应中古调式。通常把第 7 级升到距主音小二度；若第 6 级到新导音
形成增二度，再把第 6 级升高。Lydian 是书中例外：统一采用降 7 路径，不能保留自然 7 后把
调内和弦误当成变化和弦。由变化后的调式提取：

- V、V7；
- vii°、viiø7；
- 实际出现的增三和弦。

Dorian 与 Lydian 的色彩路径都从当前调性的主音建立，并使用降 7；再从调式本身按三度叠置提取
`5–♭7–2`。两种来源得到同一和弦时合并类型但保留两条来源路线。目录还统一检查结果是否包含
当前调性之外的音：全为调内音的候选不是“变化音色彩和弦”，不会进入该分类。因此 C 大调只
得到 `5–♭7–2`，不会把局部调式错误投影成 `1–♭3–5`，也不会保留调内的 `6–1–3`。
同一次 Lydian 降 7 音阶的三度叠置还会自然推出降 7 级上的增三和弦；它补齐增三游移家族的
第四个可听类别，来源路径保存在类型中，而不是用固定音高列表补卡。
类型目录保留 V/I 以完整呈现功能推导，但具体“副属词汇”默认去掉这个与调内属和弦重复的条目。
通常不临时主音化 VII，因此功能目标音级只取 I–VI。

简单构造与上述目录一致：对目标音级向上纯五度建立大三和弦或大小七和弦；目标下方小二度建立
副导三/七和弦。副导七按局部主音的导音关系定义，始终是半减七；中古调式只记录来源与变化音
路径，不能用该调式第七级的自然叠置结果改写副导七性质。简单构造得到的类型是目录子集，不替代
调式派生的色彩和弦。

## 3. 章节进行与规则

入口：

- `SchoenbergSecondaryDominantChapter.harmonyTypes(key)`：共享和声类型列表；
- `harmonyChoices(key)`：去掉调内 V/I 与当前词汇下无法形成三槽练习的条目后，列出具体副属、
  副导、增三与 `5–♭7–2` 和弦；
- `enumerate(key, secondaryHarmonyId)`：只为先选中的具体和弦枚举“预备—应用和弦—目标”三槽进行；
- `program(key, progression)`：固定符号进行并生成四部约束程序；
- 练习 id：`schoenberg.secondary-harmony`，挂“大小调通用”分支。

桌面与 exploration 协议通过通用 `selections` 中的 `secondary-harmony` key 保留这一级选择：
该综合练习必须先选具体和弦，再选枚举进行；所选进行若不含该和弦会在求解入口被拒绝，不能绕过
第一层选择。

枚举优先使用能预备七音、减五度或增五度的前一和弦。后继包含局部主音，并覆盖局部 V–I
以及到局部 VI / IV 的阻碍终止。章节复用一般四部写作、七音预备/下行解决、减/增五度预备、
禁重复与完整性规则，不启用 textbook 的具体和弦模块。

副属功能的三音、副导和弦的根音以及调式增三和弦的增五音，使用同一局部导音要求上行到临时
主音。它是按副属槽位限定的规则，不与全局小调转折点并存：例如 a 小调
`B–D♯–F♯ → E` 中，`♯4` 作为 V/V 的三音进行到 `5`，不再被全局规则强迫到 `♯5`。
应用和声相邻对也由其自身的预备/功能解决规则判定，不再叠加普通综合练习的“相邻必须有共同音”；
否则小调 `V/ii → ii` 等本来合法的功能解决会在候选生成阶段被提前删除。

## 4. 自由求解器与协议

`DiatonicChordVocabulary.forContext(..., includeSecondaryHarmony = true)` 把共享目录展开到自由
求解器词汇；`includeModalSecondaryColors` 控制是否包含增三和弦与下行调式色彩。
`FreeHarmonyRuleProvider` 从 `ChordInterpretation` 的 typed tone roles、lens 与 attributes 读取功能信息，以软倾向规则
处理局部导音；小调中优先采用局部副属解释，避免回退到全局 `♯4→♯5`。

`SymbolicChordSpecView` 序列化 `rootAlteration / appliedToDegree / secondaryFamily / modalOrigins`。
桌面进行选择器据此显示变化根音与 `/x`，例如 `II/V`、`♯iv°/V`；往返 solve 时这些字段原样
恢复，不能只传 degree/quality 后重新猜功能。

综合科技树只设一个 `schoenberg.secondary-harmony` 通用阶段，排列在“自由处理七和弦与导和弦”
之后；不拆成大调、小调两个入口，调式由练习内的调性选择器决定。该阶段累计全部三和弦转位、
七和弦转位与具体副属目录，先选具体应用和弦，再枚举必须含该和弦且带
`SECONDARY_HARMONY` 标签的长进行。枚举与四部程序共享预备、解决判定，局部导音以
`TargetSelector.identityKeys` 精确限定开放和弦身份；禁忌表生成器自动投影新增 typed 邻接规则。

## 5. 验收

- 类型目录覆盖 V/x、V7/x、vii°/x、导七、按音响聚合的增三和弦与 Lydian `5–♭7–2`，不含 `/VII`；
- 调式色彩只保留实际含变化音的推导结果；C 大调恰为一个 `5–♭7–2`；
- 枚举同时出现正格与阻碍解决，所有进行只含一个副属功能槽；
- 指定 `secondaryHarmonyId` 后，枚举结果全部只含该具体和弦；
- 同一个综合副属阶段在练习内切换大、小调后，都能枚举含所选应用和弦并满足局部解决的长进行；
- a 小调 `2–♯4–6` 的局部导音可到 `5`，且四部程序可解；
- 自由词汇开关加入相同目录中的 `ChordInterpretation`，并保留同音集合的所有解释；
- 新字段经 exploration 协议和桌面标签完整往返。

## 6. 自由练习投影

章节注册表把具体应用和弦—解决二槽投影到自由练习。默认只公开 `V/V–V` 及在 V 前插入 I64
的变体；选中任一精确副属、副导或调式色彩解释时，显示该解释允许的局部正格与 VI/IV 类比阻碍
解决。投影直接携带 `ChordInterpretationRef` 和低音，不用 `II/V` 一类全局根音字符串反查；
显示层按局部功能规范写作 `V/V`、`vii°/V` 等。
