## I0 — 回合制巴洛克前奏曲（垂直切片）

目的：在不背实时性风险的前提下，验证核心假设——**用户通过两维意图选择获得"在即兴"
的因果感，而不是在筛选算法结果**。

范围：

- 新建 `:improv` 模块：`ImprovState` / `IntentCatalog`（结构意图 6 项：停留、进入前属、
  半终止、正格终止、假终止、五度序进；表面意图 4 项：柱式、分解上/下行、密度±）/
  `IntentCompiler` / `SurfaceRealizer` v1 / `ImprovTimeline`；
- 桌面即兴面板（回合制）：候选卡片两列 + 键盘映射 + 已提交段落乐谱渲染；
- 衔接材料（上段末 frame 作 FixedPitch）与决策轨 `mecon.improv.decision`；
- 求解耗时基准测试（I1 入场判据的数据来源）。

验收判据：

- 在 C 大调与 a 小调各完成一首 16 小节前奏曲，全程只通过意图选择；
- 每次裁决 ≤1s 返回 ≥3 张结构上不同的候选卡片，每张附终止性/稳定度特征与规则解释；
- 段边界无平行五度等 HARD 违规（跨段 transition 检查生效）；
- 会话产物为标准 `.mecon`，可在编辑器中打开、修改、播放；
- 会话日志 + seed 重放得到相同候选序列。

## I1 — 实时会话循环

范围：

- 节拍时钟 + 双缓冲前瞻调度（design.md §8.2）：惯性意图必解、deadline 提交、
  无输入自动延续；
- 增量播放：MidiDevice Receiver 直接调度（audio §4.4 低延迟路径首个用例），
  fallback 分段 Sequencer；
- 表面意图即时切换（下一拍生效）；张力条 v1（启发式）；
- 撤回语义调整：实时模式不撤回已播放段，改为"标记重来点"供会话后编辑。

验收判据：

- 90 BPM、4/4 下连续演奏 ≥64 小节不中断、无 underrun（含全程不操作的纯惯性播放）；
- 从按键到结构变化可闻 ≤1 个裁决周期（1–2 小节）；表面切换 ≤1 拍；
- 求解基准：单次裁决（含 K=8 多样化搜索）P95 低于半个裁决周期。

增强项（非阻塞）：diverse-search 多样化重启落地后，卡片结构差异度由搜索期距离门槛
保证；此前用首解 + 显示层去重过渡。

## I2 — 表面装饰与和声节奏

范围（依赖 theory figuration F0–F2 落地）：

- `MeterPlan` 接入：槽位时值由意图控制（和声节奏加倍/减半成为表面意图）；
- figuration Stage 2 作为 SurfaceRealizer 的装饰后端：经过音/辅助音（p / n）、
  挂留链（4–3 / 7–6）、装饰高声部成为可选表面意图，外音自带 finding 解释；
- 留白 / 回声 / 织体密度细化；`PedalAt` 落地后补属持续音结构意图（F4）。

验收判据：同一骨架切换"柱式 → 挂留链 → 装饰高声部"听感明显不同且外音分类
（`NonChordToneClassifier`）全部合法；装饰不破坏骨架层规则检查。

## I3 — 调性运动与离调可视化

范围（依赖 theory M5 半音化词汇 + `KeyPlanSpec`）：

- 结构意图扩展：主音化 V、进入近关系调（vi / IV / V 区域）、回归、欺骗性转向；
- `LocalCenter` 状态机（CANDIDATE / TONICIZED / CONFIRMED）+ 置信度；
- 三套坐标显示（全局 / 局部 / 和弦内）+ 双圈离调图 + 调性距离卡片特征；
- 中期时间尺度操作（concept.md §六）：4–8 小节的转调计划与高潮位置意图。

验收判据：C 大调会话中主音化 G 后，同一 F♯ 在三套坐标下分别显示 ♯4 / 7 of G /
3rd of D7；持续 + 终止式后状态升级为"已确认转调"；随时可经"回归"意图安全返回主调。

## I4 — 爵士固定 changes 模式

范围：

- 固定曲式 + changes（12 小节布鲁斯、ii–V–I 标准曲）+ 伴奏轨模板（bass / 鼓 /
  comping，写入普通轨道循环播放）；
- 结构维度换为**和声解释**：inside、导音连接（guide-tone `LinePattern`）、延迟解决；
  表面维度：动机重复/移位、密度、留白、缩短/扩展；
- realizer 引入 swing / 微观时值偏移层；
- I4b（依赖半音化词汇成熟）：altered、三全音替代、侧滑、turnaround 改写（开放和声，
  concept.md §十二第三阶段）。

依赖：`LinePattern` 自动机（constraint-program §3 🚧）承载 guide-tone 线；
`Chord.pitchClasses` 扩展和弦 interval 表补全（theory README §4 既有欠账）。

验收判据：Dm7–G7–Cmaj7 上选择"导音连接 + 重复动机缩短"产生 3–7 音连贯连接线；
切换 inside / 延迟解决听感可辨；伴奏与独奏不冲突。

## I5 — 动机、个性化与控制器

范围：

- 动机捕捉：从已提交段落圈选 → `MotiveShape` 抽取（analysis/motive §2），作为会话
  动机材料；表面意图接 `MotiveAt` 自动机（移位/倒影/缩减）；
- 个性化排序：会话日志 → 轻量排序器（design.md §11），仅重排不生成；
- MIDI 键盘按钮阵列映射（白键 = 候选、黑键 = 保持/回退/试听、踏板 = 惯性）；
- 评估众赞歌前奏曲模式立项（已有旋律 + 处理方式选择）。

## 明确不做 / 后置

- **赋格即兴**：复杂度显著高于和声填充（concept.md §三.4），不入路线图；
- **神经网络直接生成音乐**：始终只做候选排序；
- **平板 / 手机 UI、3D 打印控制器**：交互模型经桌面验证稳定后另行评估；
- **自由无调性即兴**：词汇表机制不排斥，但不主动设计。

## 对乐理 / 音频 roadmap 的反向输入

即兴模块给既有 roadmap 增加的优先级理由（不改变其内部排序，仅供权衡）：

- diverse-search 落地（theory P3.3）→ I1 卡片质量；
- figuration F0–F2（theory P2）→ I2 全部内容；
- M5 半音化词汇（theory P3）→ I3 全部内容；
- LinePattern 自动机（S2 剩余）→ I4 guide-tone；
- 低延迟 MIDI 路径（audio §4.4）→ I1 增量播放；
- `RuleFinding` messageKey i18n 化 → 卡片解释文案直接受益。
