# 自由练习惯用进行扩充与交互修复计划

> 状态：已实施，2026-08-04。本文保留设计决策、迁移顺序与验收基线；跨调目标词汇过滤与
> 目标调筛选已在后续阶段落地。
> 现状说明见 [勋伯格自由练习](../theory/schoenberg/free-practice.md)，自动配和边界见
> [自由练习自动写作改造](free-practice-auto-writing.md)。

## 1. 目标与边界

本轮完成四件事：

1. 补齐自由练习默认惯用进行，并直接复用教材章节的关系、枚举与 typed 声部规则；
2. 所选和弦驱动相关进行，副属、减七、拿坡里、增六等按具体功能解释显示；
3. 支持进行共享和弦与 I64 中插，例如 `V/V–V` 和 `V–I` 组合为 `V/V–V–I`；
4. 修复整组插入 `V–I` 后自动写作仍保留旧 I、听成 `I–I` 的问题。

首轮不实现跨调目标词汇、任意调域自动创建、右边界自动配和或装饰音生成。不同调域互接所需的
“关系 + 可选词汇过滤”接口在首轮建立；后续已增加显式“展示离调”开关，仍不自动创建调性线。

## 2. 动工前确认的现状与根因

### 2.1 目录丢失了教材已有结构

`SchoenbergFreePracticeCatalog` 目前只有终止式和远关系转调两个章节贡献。终止式贡献虽然调用
`SchoenbergCadenceChapter.enumerate`，但随后只截取 `HarmonicPatterns` 的二和弦窗口，导致章节
已经生成的前属和弦与可选 I64 被丢弃。副属、减七、增六、小下属和拿坡里章节尚未注册贡献。

### 2.2 `V–I` 实际成为 `I–I`

问题不是求解器把 V 解释成 I，而是整组插入时写作范围少包含了第一个和弦：

1. 初始 I 已有音符；在同一位置插入 `V–I` 后，workspace 的首槽变成 V，但谱面仍暂存旧 I；
2. Workbench 只把惯用进行最后一槽作为自动写作 trigger；回溯为 0 时只求解末槽 I；
3. `FreePracticeMaterialProjector` 把首槽的旧 I 音符视为可用左边界，未校验它是否属于新 V；
4. 物化器只替换末槽，于是谱面最终保留旧 I，再写一个新 I。

修复必须同时做到：惯用进行插入/替换传入完整复合范围；左边界的实际音高还要与当前槽的和弦
目标相符。只增加回溯默认值会掩盖同类 stale-material 问题，不作为修复。

### 2.3 当前模型禁止重叠

`WorkspaceHarmonySlot.idiomInstanceId` 是单值所有权，插入器显式拒绝覆盖另一惯用进行；删除实例
也会删除它拥有的全部槽。因此两个实例不能共享 V，UI 也只能从槽反查一个实例。

### 2.4 类拿坡里混合了关系与练习过滤

`enumerateAnalogousNeapolitanConnections` 把“根音高于局部主音半音、接局部 I64–V”的关系，
和“局部主音必须是母调自然三和弦、末槽必须来自母调副属目录”的练习词汇限制写在同一函数。
前者是教材关系本体，后者只是当前非转调练习的候选过滤，必须拆开。

## 3. 首版目录

默认目录按下表提供确定、可求解的具体变体；小写 `iv` 表示实际小下属和弦解释，不再只按
`degree=4` 粗匹配。拿坡里默认使用教材的 `N6`，增六包含 It/Ger/Fr 三族。

| 分类 | 直接形式 | 在 V 前插入 I64 |
|------|----------|-----------------|
| 完整正格终止 | `ii–V–I`、`IV–V–I` | `ii–I64–V–I`、`IV–I64–V–I` |
| 正格终止 | `V–I` | — |
| 阻碍终止 | `V–vi`、`V–iv` | — |
| 调内属前 | `ii–V`、`IV–V` | `ii–I64–V`、`IV–I64–V` |
| 副属属前 | `V/V–V` | `V/V–I64–V` |
| 拿坡里属前 | `N6–V` | `N6–I64–V` |
| 增六属前 | `It+6/Ger+6/Fr+6–V` | 对应的 `+6–I64–V` |

排序为：短的直接终止、完整终止、属前、I64 变体；同类再按教材 family 的稳定顺序。目录按
具体解释去重，不按可听 pitch-class 集合吞掉副属、减七或等音增六线路。

## 4. 章节复用与贡献范围

自由练习仍只遍历 `SchoenbergChapterRegistry`，桌面层不增加 exercise-id 白名单。首轮接入：

| 章节 | 自由练习贡献 | 复用本体 |
|------|--------------|----------|
| Cadence | 正格、阻碍、ii/IV 完整终止及 I64 变体 | `SchoenbergCadencePolicy` 的后缀和 selector |
| Secondary harmony | `V/V–V`；所选副属的类比正格与 VI/IV 阻碍解决 | `allowsResolution`、局部导音 requirement |
| Diminished seventh | 所选具体减七用法的类比属功能解决 | 省根属九 usage、局部导音和变化音 requirement |
| Minor subdominant | `N6–V`、`N6–I64–V`；类拿坡里连接 | 拿坡里离开规则、类拿坡里关系 |
| Augmented sixth | 指向 V 的三族直接/I64 进行；所选和弦的目标与 Ger 阻碍解决 | endpoint requirements 与 family 元数据 |
| Distant modulation | 多调性和声选择顶部的四个升降号内枢纽推荐；独立 `V–VI–V` 属持续音 | 公共和弦目录、既有 pivot/ESTABLISHED compile 结果 |

原位共同音、一般六和弦、根音方向与反复等是“写作技术/生成条件”，不是稳定命名的短进行；不把
它们的任意枚举结果全部塞进目录。若其中存在有名称的固定结构，后续也通过同一贡献接口单独声明。

## 5. 关系与可选过滤

新增章节级公共契约，名称可在实现时按现有命名调整，但职责固定：

- **连接关系**：只描述源和弦、局部目标、允许的类比正格/阻碍目标、I64 位置及 typed 声部要求；
- **候选过滤**：接收关系产出的候选，决定哪些和弦属于当前练习词汇；
- **目录投影**：把通过过滤的具体 `ChordInterpretationRef` 投影为可插入步骤，不复制关系公式。

首版提供 `StudiedInActiveKey` 过滤并同时用于教材练习与自由练习。接口预留 `StudiedInTargetKey`
和无过滤策略，但本轮不在 UI 开放。审计并拆分以下混合点：

| 位置 | 关系本体 | 当前可选过滤 |
|------|----------|--------------|
| 类拿坡里 | 大六根音下行半音到局部 I64，低音保持到局部 V | 调内已学和弦/副属词汇 |
| 副属 | 指向局部 I，并可类比到局部 VI/IV | 当前 key 的可用目标三和弦 |
| 减七 | 所选省根属九解释指向局部属目标 | 当前 key 的已登记 usage/目标 |
| 增六 | 两端汇聚到解释声明的目标音 | 当前 key 的已学目标和弦 |
| 小下属连接 | 借入和弦的变化音进入/离开关系 | 当前自然音前后文 |

这样以后接“减七、增三、拿坡里、副属、增六跨领域互接”时，只替换/组合过滤与目标调上下文，
不改教材关系本身，也不在 enumerate 与 program 两侧另写判断。

## 6. 目录 DTO 与所选和弦查询

`SchoenbergFreePracticeIdiomVariant` 从平行的字符串/时值列表收敛为 typed steps。每步至少携带
精确解释引用、显示符号、时值和本轮使用的调性绑定；变体另存 `anchorStepIndex` 与关系标签。
字符串只用于显示，插入时不再由桌面 `resolveExactChordChoices` 反查。

目录发现请求增加可选的所选和弦 focus：

- 无 focus：返回第 3 节默认目录；
- 锁定解释：只返回以该 `ChordInterpretationRef` 为 anchor 的进行；
- 未锁定音响：返回活动调性下所有兼容解释的并集，并明确标注线路；
- 昂贵枚举继续在后台运行，以调性、focus fingerprint 和过滤策略为 key，不在 Compose 主线程扫描。

副属 focus 显示其类比 `V–I` 与类比阻碍目标；减七必须先按具体 usage 区分同一对称音响的不同
解决；增六按 family/目标显示。面板优先显示“与当前和弦相关”，并保留折叠的“全部教材进行”。

点击进行时把 anchor 与当前槽对齐，而不是总把第一步放在当前 onset。若前置步骤会越过谱首或
所需调性布局不覆盖完整范围，按钮禁用并给出原因。

## 7. I64 组合与进行重叠

I64 是进行内部的结构变体：章节贡献先给出 base formula，再由共享的“在目标 V 前插入终止四六”
变换生成具体步骤。它不是追加在进行尾部，也不由 UI 临时拼字符串。

不同惯用进行的组合保留为不同实例，但允许共享兼容和弦槽：

```text
实例 A：V/V ─ V
实例 B：      V ─ I
时间轴：V/V ─ V ─ I
```

兼容判据使用同一调性布局中的精确和弦解释、低音约束和时间边界；不能只比较显示符号。边界不齐时
先按 incoming step 边界切分兼容槽，再共享对应片段；实际和弦冲突则原子拒绝并保持原 state 引用。

## 8. workspace 与 schema v7

先更新 `docs/data_model/free-practice.md`，再修改模型。目标是让
`WorkspaceIdiomInstance.slotIds` 成为成员关系真相，槽到实例的索引从 instances 派生；单值
`WorkspaceHarmonySlot.idiomInstanceId` 退为 v6 解码输入并在 v7 迁移后不再写出。

- 一个槽可被 0..N 个实例引用；被任一实例引用时仍禁止逐槽破坏性编辑；
- 插入优先复用/切分兼容槽，新建其余槽，并让新实例记录最终稳定 slot ids；
- 删除实例只解除成员关系并保留全部和弦槽；共享槽继续受其他实例锁定，其余槽转为普通时间轴和弦；
- 替换实例先对其他实例做冲突检查；共享步骤不变可复用，试图改写共享和弦则拒绝；
- UI 从派生 membership 显示多个括号/标签，点击共享槽时可选择相关实例；
- v6 文件中的 instance 本来已保存完整 `slotIds`；迁移以它为真相并忽略槽级单值
  `idiomInstanceId`，覆盖保存/打开与重叠 round-trip 测试。

本轮继续保留“一个实例使用一个 tonal layout”的插入限制；关系/过滤 API 不依赖此限制，为未来
逐步调性绑定留出空间。

## 9. 自动写作修复

惯用进行命令返回实际新增、改写或重新解释的稳定槽集合。Workbench/host 使用显式复合 scope，
一次求解和一次事务覆盖整个集合；普通单和弦替换仍使用现有 trigger/backtrack 规划。

边界投影增加和声一致性检查：完整纵向的实际 pitch classes 必须能匹配当前槽允许的 target，才能
成为 `BOUNDARY_READY`；否则视为 stale/partial，不把旧材料冒充新和弦边界。求解后还要断言每个
solution target 属于对应槽允许域，再交给物化器。

## 11. 验收矩阵

- C 大调与小调的默认目录覆盖第 3 节，顺序稳定、无解释误去重；所有显示变体至少有一个四部解；
- 插入 `V–I` 覆盖已有 I 时，两槽实际 pitch classes 分别属于 V 与 I，且一次 undo 完整恢复；
- `V/V–V` 与 `V–I` 共享同一稳定 V 槽；删除任一实例不破坏另一个；冲突替换原子失败；
- `ii–I64–V–I` 和 `N6–I64–V` 的 I64 位于中途，低音/转位和章节规则正确；
- 选择 V/V 后只显示其正格/阻碍类比；同一减七音响锁定不同 usage 时得到不同解决；
- 未锁定多解释音响不静默取第一条，跨活动调性线路有明确标签；
- 教材与自由练习启用同一 `StudiedInActiveKey` 过滤；关闭过滤的领域级单测证明关系本体可在
  非自然音目标上成立，但本轮 UI 不暴露该能力；
- 插入、替换、重叠、自动写作、保存打开各自产生正确的单步 undo/redo；v6 文件无损迁到 v7；
- 目录发现和求解均在后台，切换所选槽时旧 focus 结果不能覆盖新状态。

## 12. 评审确认点

计划按以下语义实施，若需调整应在动工前确认：

1. `V–iv` 指实际小下属 iv，而不是任意四级和弦；
2. 只共享精确解释、低音与时间兼容的步骤；冲突不自动改写其他惯用进行；
3. 通用写作技术练习不批量转成“惯用进行”，只接有稳定功能关系的短结构；
4. 自由练习默认启用调内已学词汇过滤；“展示离调”显式打开后才枚举目标调词汇并允许等音 focus。

## 13. 实施结果

- 目录步骤现携带精确 `ChordInterpretationRef`、低音与 anchor；默认覆盖终止、属前、副属、拿坡里
  和三族增六，I64 由共享变换插在 V 之前；
- 副属、调式增三、减七、拿坡里、类拿坡里和增六由章节注册表贡献；选中槽按精确解释查询，
  未锁定解释时按音响并集查询；
- `WorkspaceIdiomInstance.slotIds` 已成为 schema v7 的唯一成员关系，一个槽可属于多个实例；
  reducer 覆盖共享、切分、删除保留与冲突替换，时间轴用分轨标记展示重叠实例；
- 惯用进行插入按 anchor 对齐并传递完整自动写作 scope；scope 会继续向左吸收连续“已选但未写”的
  前置槽（包括新建工作区尚未写音符的首个 I），旧材料则只有与当前和弦域一致时才可作左边界；
  `V–I` 不再留下旧 I 形成 `I–I`；
- 类拿坡里关系已与 `StudiedInActiveKey` 候选过滤拆分；当前教材和自由练习都启用该过滤，
  `None` 为领域级测试和后续目标调过滤保留；
- 目录枚举产出可复用的不可变索引。默认列表先从只含默认材料的轻量索引发布，完整相关材料索引并行
  在后台完成；实测默认索引约 198 ms，避免被副属与类拿坡里的完整关系枚举阻塞。切换同一调性内的
  和弦随后只做内存筛选，不再重新运行章节枚举；实测 11 种真实和弦的 focus 投影为 0–3 ms。
  跨调性索引仍在后台加载，并分别显示默认目录与当前和弦的加载状态；
- focus 只能匹配变体原本声明的 `anchorStepIndex`，不得在全部步骤中搜索命中后改写 anchor。因此选择
  解决目标 I 不会把以减七源和弦为 anchor 的“减七和弦的属功能解决”列为相关进行。
- 惯用进行的枚举转位不再自动变成固定低音。目录从章节规则投影真正的转位约束：终止式末尾
  `V–I` 固定原位，插入的终止 `I64` 固定第二转位；前属、阻碍终止、终止式衍生、副属、拿坡里、
  增六及其他连接均可修改低音。普通三和弦选择五音低音时只提示四六和弦通常不建议使用，不作硬限制。
- 德国增六等音“作为属七”复用终止式时，分类显示“作为属七的终止式”；该称呼绑定目标读法，
  不检查由哪一种源和弦充当属七。作为目标的后继和弦不继承正格终止的原位锁定。
- 七和弦变体由章节词汇对普通三和弦步骤作组合扩展，排除终止四六与正格终止末尾 I/i；拿坡里保留
  对应转位。半减七增六到拿坡里进入默认目录。
- “展示离调”只扩展当前和弦相关材料：按大/小调式各枚举一次关系，再把变体投影到目标调目录并
  附加最短五度圈距离；“全部教材进行”始终使用本调轻量目录，副属/副导进行不作跨调重复投影。
  目标调筛选不改变 workspace schema。半减七/`ø+6`、Fr+6 双向目标及离调减七/增三通过等音
  focus 显示。Ger+6 不依赖该开关，而是自动复用其等音目标调的主属七惯用进行，并按本调重标记
  `Ger+6–♭II` 等身份，不维护单独线路。“视作”投影对进行的每一步都重新查询本调精确解释，目标
  同样允许识别成拿坡里等变化音和弦；全部步骤均可重解释时直接插入当前调性线，并保留原调解释供
  教学规则投影，只有无法完整重解释时才要求原目标调性线。显示层按可听音响、低音与时值跨分组
  去重，同音进行只保留调号偏离最少者；调号距离只在离调开关打开时出现。

## 14. 进行选择与覆盖交互（2026-08-05）

- 时间轴括号与进行首和弦共享同一选择语义：点击括号会定位首和弦，点击首和弦会高亮括号；
  点击进行中间或末尾和弦只选择和弦，不把任一覆盖实例隐式选中。
- “和声选择”顶部显示当前功能符号与组成音，提供上一和弦、下一和弦和末尾和弦导航；首尾禁用
  不可用方向。其下按起始时间列出覆盖当前和弦的全部进行，起始于当前和弦者强调显示，均可删除。
- 独立“已插入的惯用进行”面板已移除。选中实例后，惯用进行目录直接高亮其 definition/variant；
  点击其他目录项原子覆盖当前实例，并保留实例 id 供时间轴选择稳定跟随。
- Workbench 仅在用户手动选和弦、改低音/转位或移动时间轴和弦时更新瞬态的
  `lastUserEditedOnset`；惯用进行自动填充不更新该标记。长进行覆盖成短进行时，若标记尚未到达
  缩短后多出的尾段，则 reducer 删除该未编辑尾段；若用户已经编辑到尾段，则保留为普通和声槽。

## 15. 基础进行与和弦规模轴（2026-08-18）

- 教学目录继续保留章节产出的全部具体变体，供 session 校验、插入、替换与规则投影；面板改为消费
  `PracticeIdiomChoiceView`，默认每个 definition 只列一个基础公式。例如“完整的正格终止”只列
  `ii–V–I`，不再把 `ii7–V–I`、`ii–V7–I`、`ii7–V7–I` 各画成独立按钮。
- 具体变体以去除和弦规模后的 `structureId` 归组。插入基础进行后，`PracticeSelectedIdiomFormView`
  在面板顶部列出可调整步骤；`SetIdiomChordToneCount` 由共享 session 在同一结构内寻找目标变体并
  原子替换，Desktop/Web 不拼 variant id，也不自行推导和弦。
- 规模切换的候选 family 同时包含 `structureId`、目标调 `suggestedKey` 与重解释谱系
  `interpretationContextId`。例如把本调 V7 视作离调 Ger+6 后，将尾部 V 改为 V7 仍留在同一目标调，
  不得因本调存在同形 `Ger+6–V7` 而串回本调。
- 规模轴在 wire 上使用开放的 `toneCount: Int`，不固定为三/七和弦枚举。当前标签为三和弦、七和弦；
  未来九、十一、十三和弦沿同一轴扩展，基础公式、平台组件和 intent 形状均不需要重做。
- “与当前和弦相关”仍可展示与 focus 匹配的其他基础公式；“全部教材进行”只展示每类首选基础公式。
  离调目标调仍是 choice 身份的一部分，不能把不同目标调的同形公式合并为一个按钮。
