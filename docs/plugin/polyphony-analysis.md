# 复调分析助手

> 状态：总开关、音级轨道、经过和弦、和弦外音区间和调性模糊区域已实现。

## 1. 入口与职责

复调助手与和弦分析共用 `plugins/chord-analysis`：

- `core/.../PolyphonyAnalysisModels.kt`：持久化事件与会话显示开关；
- `core/.../PolyphonyAnalysis.kt`：活动音快照、调性解析、和弦识别与谱面注释；
- `desktop/.../PolyphonyAssistantPanel.kt`：音符区间和调性区域编辑器；
- `apps/desktop-ui-kit/.../CircleOfFifthsPicker.kt`：与探索页共用的五度圈。

Computed / 插件层决定展示哪些音级、经过和弦与调性边界。Renderer 只测量、分轨和定位
`AnnotationElement`，不包含和弦识别或调性判断。

## 2. 谱面展示

`PolyphonyAnnotationProvider` 使用 `AboveAllStaves`，每个系统上方只有一条可扩高的分析带：

- 每个活动音变化边界建立一个 `PolyphonyTimeFrame`；
- 活动音按音高从高到低竖排，所选音头对应数字高亮；
- 模糊区内每个音显示所有候选调下的音级；
- 助手总开关打开时，钢琴卷轴音符同步显示相同音级；模糊区同样列出多个调的标签；
- 用户和弦由原 `ChordAnnotationProvider` 展示；
- 未标记、完整且唯一识别、并与前一和弦不同的和弦显示为较小字号的经过和弦；
- 用户指定的和弦外音片段在其半开时间区间内不参与自动和弦识别。

经过和弦只在活动声部集合改变的边界识别，不在连续时间轴上采样。身份比较采用根音与性质，
忽略转位，避免同一和弦因低音声部移动反复标记。
音级文字不可点击，但仍携带 `systemIndex`；分页结果按系统归页，不能用其零尺寸 hitBox
推断页面，否则第二页起的音级会被错误装入第一页。

## 3. 区间交互

选择单个音头后，面板用 RangeSlider 在该音符时值内选择起止比例，并写入
`StorageNonChordToneEvent`。这既支持整音，也支持延音中间的一小段；列表可定位并删除已有
标记。复音事件必须先选具体音头，避免误把整个和弦同时排除。

调性区域使用当前音符选择范围作为起止边界。五度圈允许多选候选调；候选超过一个即为调性
模糊区域。区间末端可以从候选中指定 `resolvedKey`，之后的时间沿用该中心，直到后续区域
重新解释调性。点击谱面区域边界可回到同一编辑器调整候选、终点中心或删除；尚未进入人工
区域时才读取谱面原生调号。

## 4. 增量策略

`PolyphonyAnalysisEngine` 缓存按 TimeCode 排序的帧：

1. 音符树通过 `TimeIndexedList.changedSpan` 找到结构共享后的最小变化区；
2. 窗口向右扩到旧 / 新事件可能发声的最晚终点；
3. 只重建窗口内的活动音、音级和和弦，窗口外帧复用；
4. 和弦外音、调性区域或原生调号序列变化时重建分析快照。

插件事件编辑仍通过 `ScoreSession.applyPluginEdit` 携带受影响小节范围，让现有增量
compute / layout / render 管线只替换相关系统。显示开关属于会话状态，不进入乐谱或撤销历史。

## 5. 已知边界

- 自动和弦仅接受完整且唯一的识别结果；不完整音响或多解音响不猜测；
- 单谱表 `AboveStaff` / `BelowStaff` 锚定尚未实现，助手目前按整行系统展示；
- 音级、和弦身份与调性解释使用十二平均律 pitch class；微分音分析仍为 🚧。
