# 国际化 (i18n)

> 桌面端实现路径：
> - `apps/desktop-ui-kit/.../i18n/` — `Language` / `I18nRegistry` / `i18n()`（共享给插件）
> - `apps/desktop/.../i18n/BuiltinStrings.kt` — 主壳内置资源
> - `apps/desktop/.../i18n/*Strings.kt` — 主壳功能页自带 i18n 包（例如探索页）
> - `plugins/<name>/desktop/.../*.Strings.kt` — 各插件自带 i18n 包

当前支持 **中文（简体）** 与 **English**，可在应用内切换。

## 1. 核心文件

| 文件 | 职责 |
|------|------|
| `Language.kt` | `enum class Language { CHINESE, ENGLISH }` |
| `I18nRegistry.kt` | 注册中心：`register(language, map)` 合并各模块字符串 |
| `BuiltinStrings.kt` | 主壳菜单 / 工具栏 / 面板等键，启动时 `install()` |
| `i18n/ExplorationStrings.kt` | 探索页界面与规则标签键，启动时 `install()` |
| `<plugin>/ChordAnalysisStrings.kt` | 插件自带键，插件 `install()` 中注册 |

## 2. 在 Composable 中使用

```kotlin
// 读取字符串
Text(i18n("menu.file"))           // 全局便捷函数
Text(Strings.get("toolbar.save")) // 等价形式

// 切换语言（TopBar 语言选择对话框）
Strings.setLanguage(Language.ENGLISH)
```

`Strings` 是全局单例，切换后下一次 Compose 重组时自动反映新语言（需配合 `mutableStateOf` 触发重组）。

## 3. 添加新字符串

**主壳新增**：在 `BuiltinStrings.kt` 的 `zh` 与 `en` 两个 `Map` 中同时加同一 key，调用 `i18n("your.new.key")` 使用。

**插件新增**：在插件自己的 `Strings.kt` 中维护 `zh` / `en`，并在 `MeconPlugin.install(...)` 内调用 `I18nRegistry.register(Language.X, map)`。键前缀建议 `plugin.<id>.*` 避免与主壳冲突。

## 4. 键名规范

```
{模块}.{功能}         例：menu.file / toolbar.save / dialog.openFile
{组件}.{状态/操作}    例：score.empty / playback.playing
```

## 5. 已有键一览（主要）

| 前缀 | 范围 |
|------|------|
| `menu.*` | 顶部菜单项 |
| `toolbar.*` | 工具栏按钮 |
| `tool.*` | 左侧工具 |
| `dialog.*` | 对话框标题与按钮 |
| `panel.*` | 侧栏与底部面板 |
| `score.*` | 乐谱相关提示 |

完整列表见 `Strings.kt`。
