# 小节选择与结构编辑

点击谱表五线范围内的空白位置会选择该谱表的小节单元格。选择以
`MeasureStaffSection(staffTrackId, measureNumber)` 表示；按 Shift 可增减多个单元格。
视图根据渲染空间索引绘制小节背景，编辑层则将单元格展开为对应谱表和小节中的全部
`VoiceEventSection`，所以复制、剪切和按 `Delete` 都会覆盖其中的全部音符；`Delete` 只清空
所选谱表小节单元格的音符/休止内容，不删除小节结构。

粘贴到小节单元格时，先清空该谱表此小节的所有声部，再从小节起点粘贴剪贴板内容。

选中单一 `BarlineSection` 后，切换到“编辑”页可填写数量并在该小节线之后插入小节。
删除小节暂不绑定快捷键，只能点击工具栏“删除小节”；它按小节号作用于全谱，若任一谱表中有
实际音符，先显示确认提示。插入和删除均由
`MeasureEditEngine` 生成一次全量结构提交，因此可由普通撤销/重做恢复。

“其他乐谱符号”输入面板最下方的“小节线与反复”区提供单线、双线、终止线、反向终止线、
虚线、点线，以及可独立开关的左反复/右反复。两者同时开启即为双向反复；全部取消则回到
普通单线。短线和 tick 不放在常用输入面板。支持两条等价路径：

- 先选中 `BarlineSection` 再点类型：立即通过 `BarlineEditEngine` 替换该逻辑边界并保持选中；
- 先点类型再点谱面小节线：进入 `EditTool.BARLINE`，只接受真实小节线命中；分页行末和下一行
  行首的替代线都解析为同一边界。

特殊小节线落笔一次后自动退出输入状态。反复次数移到右侧选中项属性；选中右反复可直接改，
选中左反复会解析到之后对应的结束反复再修改。次数写入结束小节的 `repeatCount`。

同一区还提供一个合并的“1./2.”房子按钮、Segno、Coda、To Coda、Fine、D.S./D.C. 及
al Fine/al Coda 组合。房子可先选边界再点按钮，或先点按钮再点边界：一房子从所选边界后的
下一小节延伸至之后第一个结束反复小节线；二房子自动从该反复线后的下一小节生成，并从右反复
小节线外侧开始，避免与一房子终点重合。选中二房子后可拖动较大的右端手柄，把结束位置吸附到
其他小节线；一房子的左端也可拖动调整起始小节。房子端点使用实际 barline layout X，不使用
音符槽位 X。一、二房子均可直接选中并用 Delete 删除。房子以
`ComputedVoltaAttachment` 进入 `StaffAttachmentLayoutComputer`，与 8va/8vb 等区间符号统一
参与碰撞、系统拆段和垂直空间预留；其上方行优先级最高，因此始终排在其他区间符号外侧。

Segno / Coda 使用 Bravura 的 SMuFL `U+E047/U+E048`；D.S./D.C. 及组合指令使用放大的
粗斜体文字，To Coda 的 Coda 部分仍使用 SMuFL。导航记号锚定实际小节线并默认排在谱表上方，
支持上述两种插入模式，落笔后自动退出；它们可选择、自由拖动并用 Delete 删除，拖动偏移持久化
到小节的 `navigationMarkOffsets`。导航记号的命中优先于其下方小节线；拖动时 Y 可自由调整，
松开后 X 吸附到最近小节线并同步更新播放导航边界。提交期间保留拖动预览直到新渲染帧到达，
避免先闪回旧位置。跨行判定使用每个系统的五线谱核心区，而不是会被附加符号扩张且可能互相
重叠的系统命中带；核心区先投影到最终画布/分页显示坐标，与原始鼠标位置直接比较，锁定系统后
只在该行的小节边界中吸附。跨系统松手时从累计预览 Y 位移中扣除源、目标系统锚点距离，只保存
相对目标谱表的局部偏移，避免系统位移在“换锚点”和 `navigationMarkOffsets.dy` 中重复应用。

房子参与分页增量排版及元素复用。附件候选索引使用房子的语义 `startMeasure`，而非边界锚点的
`TimeCode.measure`；谱首边界的时间小节号为 0，但一房子属于第 1 小节。这样局部刷新首个系统时
一、二房子都会进入候选集，不会在替换旧系统附件时漏掉一房子或留下滞后的空间索引。

强制分行 / 分页同样在“编辑”页操作。选择小节线后，“分行”“分页”按钮互斥；再次点击
当前按钮会取消边界。边界记号本身以 `LayoutBreakSection` 选择，可用 Delete 或右侧检查器删除，
但不进入音符剪贴板。若同一逻辑边界同时显示为上一行末与下一行首，`BarlineSection` 会记录
`SYSTEM_END / SYSTEM_START`：从行末插入让新小节留在分隔前，从行首插入让新小节留在分隔后。
删除跨过边界的小节时，`MeasureEditEngine` 将边界重新锚定在两侧幸存小节之间；仅当一侧已无
小节时才移除该边界。

## 谱表显示 / 隐藏

谱表可在若干小节内隐藏（数据 = `StorageStaffTrack.hiddenRanges`，编辑经 `StaffVisibilityEditEngine`，
详见 `docs/data_model/storage.md` §3.8 与 `docs/renderer/layout.md`）。

- **隐藏**：选中小节单元格（或选中小节线 = 该小节所有谱表）后，“编辑”页的 **隐藏这些小节 /
  隐藏之后所有小节** 按钮提交隐藏；若所选区域含音符则按钮置灰，悬停提示原因（`hasNotesInCells` 护栏）。
- **灰显与禁止交互**：行内部分隐藏的单元格由桌面视图灰显；音符 / 谱号笔的 ghost 在隐藏单元格上被抑制，
  无法录入。
- **虚线**：整行某谱表全程隐藏时折叠为一条水平虚线（`HiddenStaffSection`，连续隐藏合并）。
- **恢复**：右键虚线或灰区弹出两级菜单——一级为谱表名，二级为 **在该行显示谱表 / 在之后的行都显示谱表**
  （灰区另有 **显示这些区域**）；左键选中后右侧检查器提供相同动作。恢复经 `StaffVisibilityEditEngine.show`。
- 提交走 `applyMeasureEdit` 整帧重排（隐藏改变纵向布局），可普通撤销 / 重做。
